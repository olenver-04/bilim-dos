# Білім Дос — рефлексия урока

Приложение Streamlit для русскоязычной школьной рефлексии.

## Файлы

- `app.py` — логика приложения, QR-код, база SQLite и панель учителя.
- `style.css` — весь CSS оформления. Между заголовком QR-кода и изображением отступ **25px**, между изображением и кнопкой — **21px**.
- `requirements.txt` — библиотеки Python.
- `.streamlit/config.toml` — светлая тема.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

**Адреса:** `/?view=wall`, `/?view=student`, `/?view=admin`.

В настройках Secrets Streamlit Cloud добавьте:

```toml
ADMIN_PASSWORD = "укажите_свой_надёжный_пароль"
```

Ответы на общем экране автоматически обновляются каждые 3 секунды, но счётчик и технический статус зрителям не показываются. Для контроля числа ответов и экспорта CSV пользуйтесь панелью учителя. Файлы SQLite в Streamlit Community Cloud временные, поэтому сохраняйте CSV после урока.
