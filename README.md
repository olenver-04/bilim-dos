# Білім Дос 5.0 — интерактивная рефлексия для школы ✨

Русскоязычный сайт для открытого урока. Школьники переходят по QR-коду и пишут своё имя и впечатление; на экране учителя отзывы превращаются в анимированные карточки. **Учителю не нужно программировать:** тема урока, вопрос и эффекты управляются из панели.

## Что нового в версии 5.0

- **Живой персонаж**: талисман моргает, приветствует класс, машет рукой, говорит поддерживающие фразы и радуется новым мыслям.
- **Магическая отправка**: ученик видит красивое подтверждение, его новая карточка прилетает на общий экран со световой волной, линией и частицами. При нескольких ответах анимация не блокирует другие карточки.
- **Праздничный финал**: учитель запускает 18-секундное шоу. Ответы собираются к центру, появляется звезда, поздравительная надпись и конфетти. Затем общий экран возвращается автоматически. Кнопка «Остановить шоу» позволяет завершить показ раньше.
- **Пульт учителя**: управление персонажем, фоном, полётом, частицами, уведомлениями, цветовой темой, скоростью и силой эффектов. Есть тестовая реакция **без записи фальшивого ответа**.
- **Режим проектора**: отдельный адрес с компактной шапкой, удобный для демонстрации на большом экране.

Сохранены прежние функции: QR-код, русскоязычные страница ученика и общий экран, обновление отзывов каждые 3 секунды, до 24 карточек на одной сцене, полный список у учителя, CSV, изменение темы/вопроса, удаление отдельных и всех ответов, вход учителя по паролю. **Счётчики и технические индикаторы на общем экране скрыты.**

## Установка в GitHub

1. Распакуйте архив **Bilim Dos 5.0**.
2. Откройте репозиторий `bilim-dos` на GitHub, нажмите **Add file → Upload files** и перетащите содержимое распакованной папки в корень репозитория. Подтвердите замену старых файлов и сохраните коммит.
3. Убедитесь, что файлы `app.py`, `scene.py`, `control.py`, `schema.py`, `scene.css`, `scene.js`, `style.css`, `effects.json`, `requirements.txt` находятся **в корне**, а `.streamlit/config.toml` — внутри папки `.streamlit`.
4. В [Streamlit Community Cloud](https://share.streamlit.io) выберите репозиторий, ветку `main`, главный файл `app.py`. Если приложение уже подключено, новый коммит обычно запускает обновление.
5. В **App settings → Secrets** добавьте секрет **только в настройках приложения** (никогда не публикуйте настоящий пароль в GitHub):

```toml
ADMIN_PASSWORD = "придумайте_сложный_пароль"
```

После публикации (подставьте свой реальный домен Streamlit):

| Назначение | Адрес |
| --- | --- |
| Общий экран с QR-кодом | `https://ВАШ-САЙТ.streamlit.app/` |
| Страница ученика | `https://ВАШ-САЙТ.streamlit.app/?view=student` |
| Учительский пульт | `https://ВАШ-САЙТ.streamlit.app/?view=admin` |
| Режим проектора | `https://ВАШ-САЙТ.streamlit.app/?mode=projector` |

**Важно:** Streamlit не открывает автоматически страницу администратора. Войдите на `?view=admin` с паролем, настройте урок, а общий экран откройте отдельно на проекторе. Для полноэкранного режима браузера нажмите **F11**.

## Как провести урок

1. Учитель открывает **Панель учителя**, задаёт тему и вопрос для рефлексии.
2. Проверяет красивую анимацию через кнопку **«✨ Проверить эффекты»**. Эта кнопка не создаёт запись в базе.
3. Открывает **Общий экран** на проекторе. Дети сканируют QR-код и пишут своё имя и отзыв.
4. Ответы появляются на сцене с полётом карточки, речевой реакцией персонажа и мягкими частицами.
5. В конце нажимает **«🎉 Финальное шоу»**, затем скачивает CSV с результатами.

## Настройка

`effects.json` — базовые технические параметры анимации и частоты обновления. Панель учителя сохраняет рабочие изменения в SQLite, поэтому они действуют на всех открытых экранах без нового коммита. `style.css` — дизайн страниц Streamlit, `scene.css` — оформление и анимации самой сцены, `scene.js` — логика эффектов, `scene.py` — SVG и защищённая сборка HTML. `control.py` — проверка и сохранение управления, `schema.py` — сохранение данных при переходе с предыдущих схем.

Параметры по умолчанию: `refresh_seconds = 3`, `particle_count = 18`, `arrival_duration_ms = 1450`, `finale_duration_ms = 18000`.

### Полезные ограничения

- Автоматические звуки **не включены** — это удобно на уроке и не требует дополнительных разрешений браузера.
- Настройка операционной системы «уменьшить движение» отключает интенсивную анимацию. Финальное поздравление остаётся доступным в статическом виде.
- Эффекты используют только браузерный SVG, CSS и JavaScript, без платных API и внешней базы.
- **SQLite в Streamlit Community Cloud не является надёжным постоянным хранилищем.** После пересоздания контейнера ответы и настройки могут потеряться. Скачивайте CSV сразу после урока. Для долговременной работы нужен внешний сервис хранения.
- Имена и ответы видны другим участникам на общем экране; учеников не следует просить вводить телефон, адрес или личные данные.

## Тесты и локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

```bash
pip install pytest beautifulsoup4
PYTHONPATH=. python -m pytest tests/ -q
```

В репозитории не должно быть `bilim_dos.db`, `.streamlit/secrets.toml` и личных паролей: они указаны в `.gitignore`.
