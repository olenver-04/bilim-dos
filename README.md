# Білім Дос — живой школьный экран рефлексии ✨

Русскоязычный сайт на Streamlit: ученик отвечает по QR-коду, а учитель показывает красивый интерактивный кластер на проекторе. В этой версии новые ответы оживают: перемещаются из центра сцены, зажигают соединительную линию, сопровождаются конфетти, кольцом света и маленьким уведомлением с именем ученика. Школьный персонаж радуется вместе с классом.

## Структура проекта

| Файл | Назначение |
|---|---|
| `app.py` | Страницы ученика, общего экрана и учителя; SQLite; QR-код |
| `scene.py` | Расстановка 24 карточек и безопасная генерация SVG/HTML |
| `scene.css` | Вся анимация кластера: полёт, свечение, частицы, реакция персонажа |
| `scene.js` | Запуск эффектов только для новых ответов и удаление частиц после анимации |
| `effects.json` | Настройки интенсивности эффектов и частоты обновления |
| `style.css` | Дизайн страницы, карточек, формы ученика и QR-кода |
| `requirements.txt` | Зависимости Streamlit и QR-кода |
| `.streamlit/config.toml` | Светлая цветовая тема |
| `.gitignore` | Не добавляет базу данных и секреты в GitHub |

## Как установить в GitHub

1. Распакуйте архив.
2. Загрузите все файлы и папку `.streamlit` в корень своего репозитория `bilim-dos`, заменив старые версии.
3. В Streamlit Community Cloud выберите репозиторий, ветку `main` и точку входа `app.py`.
4. Если приложение уже опубликовано, оно обычно автоматически развёртывает новую версию после коммита.
5. В **App settings → Secrets** задайте пароль учителя (не в GitHub!):

```toml
ADMIN_PASSWORD = "придумайте_сложный_пароль"
```

Локальный запуск:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Адреса страниц: `/` (общий экран), `/?view=student` (ученик), `/?view=admin` (учитель).

## Настроить анимацию без изменения Python

Измените файл `effects.json`. Настройки:

- `enabled` — включить или выключить всю анимацию сцены.
- `ambient_animation` — спокойное движение персонажа, мерцание звёзд, фон.
- `arrival_animation` — полёт карточек из центра к свободному месту.
- `particles_enabled` — вспышки цветных частиц при новом ответе.
- `toast_enabled` — краткое сообщение «Новая мысль!» с именем ученика.
- `particle_count` — количество частиц на карточку, от 0 до 32.
- `max_celebrations_per_refresh` — максимум одновременных вспышек, от 0 до 4 (все новые карточки всё равно отображаются).
- `arrival_duration_ms` — время полёта, от 450 до 2600 мс.
- `toast_duration_ms` — время показа уведомления, от 1400 до 8000 мс.
- `refresh_seconds` — проверка новых ответов каждые 2–15 секунд (по умолчанию 3).

Уважает системное **уменьшение движения** (`prefers-reduced-motion`): все декоративные анимации отключаются. Автоматических звуков нет. CSS/JavaScript сцены выполняются внутри отдельного iframe и не вмешиваются в форму отправки.

## Как выглядит во время урока

- На общем экране **нет счётчиков количества ответов** и служебного индикатора обновления.
- Подпись, QR-код и кнопка находятся в **одном блоке** с отступами.
- Карточки появляются вокруг центра поочерёдно с разных сторон, чтобы композиция была сбалансированной даже после 1–4 ответов.
- При наведении/фокусе карточка показывает полный отзыв через подсказку, на самой карточке используется короткий фрагмент.
- Ученик пишет имя и отзыв; выбирать категории не нужно.
- Учитель может изменить тему и вопрос, удалить ответы, очистить рефлексию и выгрузить CSV.

**Хранение:** SQLite в бесплатном Streamlit Community Cloud может быть удалена при перезапуске приложения или пересоздании контейнера. После урока экспортируйте CSV из панели учителя.
